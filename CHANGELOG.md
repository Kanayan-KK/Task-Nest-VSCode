# Changelog

## 0.1.0

- Display explicitly configured VS Code tasks in a tree using `:` separators in task names.
- Support single-folder and multi-root workspaces.
- Run and stop tasks, restart tasks after they stop, and display running status.
- Refresh the task list manually and display all TaskNest interface text in English.
- Support Windows desktop VS Code 1.100 or later for the initial release.
